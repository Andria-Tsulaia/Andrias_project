# კვირა 3 — FE-007 (პროდუქტი) + FE-005 (კალათა)

## გაკეთდა

- FE-007: გალერეა `images.length`-ით (1 სურათი → მინიატურების გარეშე), ისრები + მობილურზე swipe,
  specs ცხრილი `Object.entries`-ით, მარაგის სამი მდგომარეობა, ოდენობის სტეპერი, `related` იმავე ბარათით.
- `key={slug}` — პროდუქტის ცვლილებისას გალერეის ინდექსი და რაოდენობა ნულდება (ტიკეტის ყველაზე ხშირი ბაგი).
- `document.title` = „{title} — Cyber“, scroll ზემოთ გადასვლისას.
- FE-005: `['cart']` ერთი წყარო (ჰედერის ბეჯი + კალათის გვერდი + ჩექაუთი).
- ორი id-ის გარჩევა: `POST /cart/items` → `productId`; `PATCH`/`DELETE` → `items[].id`.
- სტეპერის სტრატეგია — 300ms debounce + optimistic + rollback (ADR 0003).
