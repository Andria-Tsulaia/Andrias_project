## Sprint Backlog

**FE-001 · ავტორიზაციის ეკრანები** (`/login`, `/register`, `/forgot-password`)
- მარკაპი + კლიენტის ვალიდაცია; ვალიდაცია გაგზავნისას, პირველი მცდელობის შემდეგ — ცვლილებაზე
- submit ღილაკი არ ითიშება არავალიდურ ფორმაზე; შეცდომა ველის ქვეშ; focus პირველ არავალიდურ ველზე
- პაროლის toggle (aria-label იცვლება); reset-ის ნეიტრალური ტექსტი
- *Testing:* 360/768/1440, კლავიატურით სრულად, კონსოლი სუფთა

**FE-002 · API კლიენტი და საერთო კომპონენტები**
- ერთი HTTP კლიენტი (`src/api/client.ts`), შეცდომის კონვერტი, 401-ის ცენტრალური დამუშავება
- `src/shared/ui/*` ყველა მდგომარეობით (default/hover/focus/disabled/error)
- *Acceptance:* დიზაინ-სისტემის ტოკენები მხოლოდ `src/index.css`/`tailwind.config.ts`-შია

**FE-003 · კატალოგი**
- ფილტრები **მხოლოდ** `GET /categories/{slug}`-იდან (checkbox/radio/color/range)
- სორტი, ძებნა debounce 400ms, პაგინაცია; ცვლილებაზე გვერდი 1
- **ყველა პარამეტრი URL-ში** — ბმული გასაზიარებელი, F5 და „უკან“ მუშაობს
- მდგომარეობები: skeleton, error + retry, empty + clear, isFetching → გამჭვირვალე ძველი შედეგები
- *Testing:* `?brand=Lenovo,ASUS&minPrice=2000&sort=price-asc&page=2&q=air`, abort (AbortController)

**FE-005 · კალათა**
- `['cart']` ერთი წყარო (ბეჯი + გვერდი + ჩექაუთი)
- ორი id-ის გარჩევა: `productId` (POST) vs `items[].id` (PATCH/DELETE)
- სტეპერის ზღვრები, წაშლა დადასტურებით, empty state, მარაგის გაფრთხილება
- *Testing:* F5, სწრაფი დაჭერები, გამოსვლა → სხვა ანგარიშით შესვლა

**FE-004 · პროფილი და მისამართები**
- `PATCH /auth/me` მხოლოდ dirty ველებით + `currentPassword` ყოველთვის
- შეცდომების mapping: 400 → currentPassword, 409 → email, 422 → `errors.<field>`, `errors._` → „შესაცვლელი არაფერია“
- მისამართები: CRUD, `isDefault` წესები, 10-ის ლიმიტი, `invalidateQueries(['addresses'])`
- *Testing:* ჰედერის განახლება გვერდის გადატვირთვის გარეშე, F5, ნაგულისხმევის წაშლა
