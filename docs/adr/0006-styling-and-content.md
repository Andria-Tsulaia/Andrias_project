# ADR 0006 — სტილიზაცია: design tokens + ცენტრალიზებული ქართული ტექსტი

**სტატუსი:** მიღებულია · **თარიღი:** კვირა 1

## კონტექსტი

ტიკეტი: „ფერები და ზომები მხოლოდ ტოკენებიდან, არასდროს hardcode“. ასევე: „ახალი ეკრანი არ უნდა
გამოიყურებოდეს სხვა პროდუქტიდან მოტანილივით“ და „ყველაფერი მრავალჯერადი მიდის `shared/ui/`-ში“.

## გადაწყვეტილება

- **Tailwind + HSL CSS ცვლადები** `src/index.css`-ში (`--primary`, `--discount`, `--star`, `--radius`,
  `--shadow-card`…), `tailwind.config.ts`-ში მხოლოდ mapping. კომპონენტში პირდაპირი ფერი (`bg-white`,
  `text-black`) არ იწერება.
- მრავალჯერადი კომპონენტები `src/shared/ui/`-ში, თითოეული ყველა მდგომარეობით:
  default, hover, focus (ხილული ring), disabled, error.
- ქართული ინტერფეისის ყველა ტექსტი და ვალიდაციის შეტყობინება — `src/content/ka.ts`-ში.
  შრიფტი: `Noto Sans Georgian` (ქართული მხედრული) + `Inter` (ლათინური/ციფრები).

## შედეგები

- ახალი გვერდი იყენებს იმავე Button/Input/FormField/Alert-ს — ვიზუალური ერთიანობა გარანტირებულია.
- ტექსტის შეცვლა ერთ ფაილშია; კომპონენტებში literal ქართული ტექსტი არ ტრიალებს.
- ფილტრების ფერის ნიმუშებისთვის გამონაკლისია `COLOR_SWATCH` — მხოლოდ ჩვენების ცხრილი, არა დიზაინ-ტოკენი.
