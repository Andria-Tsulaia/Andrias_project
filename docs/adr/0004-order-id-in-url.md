# ADR 0004 — `orderId` კოდის ეკრანზე ინახება URL-ში

**სტატუსი:** მიღებულია · **თარიღი:** კვირა 4

## კონტექსტი

შეკვეთის შექმნის შემდეგ მომხმარებელი კოდს შეიყვანს კოდის ეკრანზე. თუ `orderId` მხოლოდ
მდგომარეობაში (state/context) ინახება, F5-ზე ან ჩანართის აღდგენისას ის იკარგება და მომხმარებელი
ვეღარ ადასტურებს გადახდას.

## გადაწყვეტილება

`orderId` არის **მარშრუტის პარამეტრი**: `/checkout/confirm/:orderId`.
ეკრანი მას `useParams()`-იდან იღებს; დამატებითი მდგომარეობა არ ინახება.

კოდი და `devCode` **URL-ში არ იდება** (ბარათის მონაცემების ანალოგიურად — არავის უნდა გამოჩნდეს ბმულში).

## შედეგები

- F5 და ბმულის გახსნა სხვა ჩანართში მუშაობს — ეკრანი ხელახლა აგებს თავს.
- უკან დაბრუნება ჩექაუთზე ქმნის ახალ შეკვეთას და ახალ კოდს (მოსალოდნელი ქცევა).
- `devCode` ავტომატურად არ ივსება ველში — სასწავლო რეჟიმი (DevTools → Network).
