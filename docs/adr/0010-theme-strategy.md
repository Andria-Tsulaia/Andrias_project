# ADR 0010: მუქი და ნათელი თემის სტრატეგია (Light / Dark / System)

## სტატუსი
მიღებულია

## კონტექსტი
აუცილებელია სამი მდგომარეობის მხარდაჭერა (`light`, `dark`, `system`) და FOUC-ის (თეთრი ეკრანის გაელვება ჩატვირთვისას) თავიდან აცილება.

## გადაწყვეტილება
1. თემა ინახება `localStorage`-ში და გამოიყენება CSS კლასი `dark` HTML ფესვზე.
2. `system` რეჟიმი უსმენს `prefers-color-scheme` მედია-ქუერის ცვლილებებს ცოცხლად.
3. FOUC-ის თავიდან ასაცილებლად, ინლაინ სკრიპტი ეშვება `index.html`-ის `<head>`-ში სანამ React აპლიკაცია დარენდერდება.

## შედეგი
მიღებულია მყისიერი და უგლოვესი გადართვა თემებს შორის მომხმარებლისთვის ოპტიმალური ვიზუალური გამოცდილებით.
