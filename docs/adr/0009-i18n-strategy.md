# ADR 0009: მრავალენოვნების (i18n) სტრატეგია

## სტატუსი
მიღებულია

## კონტექსტი
პროექტს სჭირდება ქართული და ინგლისური ენების მხარდაჭერა. API არის ერთენოვანი (ნაწილობრივი ინგლისური ველებით, როგორიცაა `nameEn`).

## გადაწყვეტილება
1. გამოყენებულია `localStorage` ენის შესანახად და `<html lang="...">` ატრიბუტის დინამიკურად განახლება.
2. UI ტექსტები სრულად ითარგმნება JSON ფაილების მეშვეობით.
3. კატეგორიებისთვის გამოიყენება `nameEn`, ხოლო ფილტრების ოფციებისთვის აგებულია ფრონტენდ რუკა. `specs` მახასიათებლები რჩება ქართულად, რადგან სერვერიდან დინამიკურად მოდის.

## შედეგი
მომხმარებელს აქვს ორენოვანი ინტერფეისი ყოველგვარი ზედმეტი სირთულის გარეშე. სწორი არქიტექტურული მიდგომა სრულმასშტაბიანი პროდუქტისთვის იქნებოდა `Accept-Language` ჰედერის გამოყენება სერვერთან კომუნიკაციისას.
